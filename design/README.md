# Wildlife Detector — フロントエンドデザイン案

Claude Design（claude.ai/design）と協働でアプリのUIを再設計するための最初の提案一式です。
すべて自己完結のHTMLモックアップで、ブラウザで直接開けます。各ファイル先頭の
`<!-- @dsCard -->` マーカーにより、そのまま Claude Design のデザインシステム
プロジェクトへ同期できる形式になっています。

## 構成

| ファイル | 内容 |
|---|---|
| `foundations/tokens.html` | カラーパレット・タイポグラフィ・部品（ボタン/チップ/トグル/メーター/スタットタイル） |
| `screens/01-input.html` | ① 画像の選択 — ドラッグ＆ドロップ主動線＋出力設定 |
| `screens/02-processing.html` | ② 検出処理 — ヒーロー進捗＋スタットタイル＋ログ |
| `screens/03-results.html` | ③ 結果 — サマリータイル＋トップ5チャート＋詳細テーブル |
| `screens/04-settings.html` | 設定 — 行形式の設定リスト |

## デザイン方針（v1提案）

- **「フィールドグリーン」**: 既存の「ナチュラルグリーン」テーマを洗練。
  深緑 `#2E6B4F` を主要アクションに、紙のような温かいニュートラル `#F6F5F1` を背景に。
- **タブ → 3ステップ・ワークフロー**: 「選択 → 処理 → 結果」を左サイドバーの
  番号付きステッパーで常時表示。設定は別枠。
- **長時間バッチ処理への配慮**: 進捗はヒーロー数値（48px）、自動保存・レジューム状態を明示、
  停止ボタンには安全性の説明を添える。
- **データ表現**: 信頼度はメーター＋数値、カテゴリは色ドット＋ラベルのチップ
  （色だけに意味を持たせない）。カテゴリカラーは CVD（色覚多様性）検証済み（隣接最小 ΔE 25.0）。
- **和名優先の2段表示**: テーブルでは和名を主、英語一般名を従、学名はイタリック。

## Claude Design との同期について

この環境（Claude Code on the Web）から claude.ai/design へ直接同期するには
デザイン認証が必要です。次のいずれかで接続できます:

1. Claude Design 側で **「Send to Claude Code Web」** を使ってプロジェクトを
   このワークスペースへ送る
2. ローカルの Claude Code CLI で `/design-login` を実行して認証後、
   `/design-sync` でこの `design/` ディレクトリをアップロードする

## 実装への落とし込み（合意後）

トークンは `gui/themes.py` の QSS に変数として展開し、サイドバー化は
`QListWidget + QStackedWidget` への置き換えで実現できます。
モックアップはあくまで方向性合意のためのもので、Qt で実装可能な範囲に収めています。
